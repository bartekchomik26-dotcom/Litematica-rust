A native Rust reimplementation of Litematica for the Horizon Minecraft client. Features schematic ghost projections, layer-by-layer building, and Easy Place verification.

## 📥 Installation

1. Click the **Download** button above.
2. Download the `.hnmod` file from the latest release.
3. Place the `.hnmod` file into your Horizon client's `mods` folder.
4. Launch Horizon launcher and hit build,
5. Launch horizon and enjoy!

## ✨ Features
*   📦 **Schematic Support:** Loads `.litematic` files.
*   👻 **Ghost Block Projection:** Renders translucent block overlays.
*   📐 **Layer-by-Layer Building:** Slice the schematic on the Y-axis.
*   🛠️ **Easy Place:** Auto-places the correct block orientation.
